# GamePlay - Expo App

Aplicação mobile em React Native desenvolvida com Expo Go para agendamento de partidas via Discord.

---

## 📱 Telas
- **Login**: Tela de autenticação com Discord.
- **Home**: Lista de partidas agendadas e filtros por categoria.
- **Detalhes do Servidor**: Informações do jogo e jogadores confirmados.
- **Agendar**: Criação e agendamento de novas partidas.

---
